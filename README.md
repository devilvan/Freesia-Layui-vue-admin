# Freesia

## 介绍
这是一款基于SpringBoot、Layui-vue-Admin、Layui-vue的后台权限、记账管理系统。

在Layui-vue-Admin的前端模板基础上对接后端数据，实现了前端页面对应的后端功能。

## 安装教程
### 前端准备
1.  进入目录freesia-admin-layvue
2.  安装yarn或pnpm（需要安装NodeJS、npm）
yarn：npm install -g yarn
pnpm: npm install -g pnpm
3.  下载依赖：
yarn：yarn install
pnpm: pnpm install
4.  本地启动项目
yarn：yarn run dev
pnpm：pnpm run dev

### 后端准备
1.   启动Redis-server：7.0.0
2.   启动MinIO
3.   IDEA配置：CSDN
