# 业务背景
网站门户基础服务，通过邮箱注册、忘记密码等功能。

# 功能列表
## 1. 注册功能
- 前端页面在登录页-登录键 下方展示"没有账号？去注册"链接
- 用户填写邮箱并校验是否符合邮箱格式，校验邮箱是否已经被注册，已注册的邮箱返回失败
- 用户填写密码并校验密码是否符合密码格式，密码格式为：6-20位，包含字母、数字、特殊字符
- 发送邮件到用户邮箱，回填邮箱验证码，验证码时效为5分钟，如果用户在5分钟内未填写验证码，验证码过期，提示用户需要重新发送验证码邮件
- 符合注册条件并验证码验证成功后，调用通用的后台方法/api/sysRegistryController/register，这个注册方法需要改造一下，前端需要的使用加密组件加密后，到达Controller解密，再进行逻辑处理
- 注册成功后，提示用户注册成功，用户可以登录系统，登录后可以查看系统功能

## 2. 登录功能的兼容
- 本次接入邮箱注册后，SysLoginController应该添加一个登录方法，用于处理邮箱登录
- 邮箱注册后用户昵称默认前缀'Freesia用户'加UUID
- 邮箱注册后用户没有默认的头像，请在项目资源文件中添加一个默认头像，并告知我路径

## 3. 忘记密码功能
- 前端页面在登录页-登录键 下方展示"忘记密码？"链接
- 用户填写邮箱并校验是否符合邮箱格式，校验邮箱是否被注册，未被注册的邮箱返回失败
- 发送邮件到用户邮箱，回填邮箱验证码，验证码时效为5分钟，如果用户在5分钟内未填写验证码，验证码过期，提示用户需要重新发送验证码邮件
- 符合注册条件并验证码验证成功后，调用通用的后台方法/api/sysRegistryController/resetPassword，这个重置密码方法需要改造一下，前端需要的使用加密组件加密后，到达Controller解密，再进行逻辑处理
- 重置密码成功后，提示用户重置密码成功，用户可以登录系统，登录后可以查看系统功能
